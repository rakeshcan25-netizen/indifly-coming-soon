# IndiFly — Coming Soon

A standalone, responsive luxury editorial landing page. It uses HTML, CSS, and a small amount of JavaScript; no build tools, framework, or backend are required.

## Preview locally

1. Extract the project folder.
2. Open `index.html` in a modern browser.
3. For best results, view it with an internet connection so the background video and hosted typefaces can load. A local SVG fallback background is included.

## Publish with GitHub Pages

1. Create a GitHub repository in an account you control.
2. Upload the contents of this folder, making sure `index.html` is at the repository root.
3. In the repository, open **Settings → Pages** and choose **Deploy from a branch**, selecting `main` and `/ (root)`.
4. After the Pages site is published, add `indiflys.com` as the custom domain in the Pages settings.
5. At GoDaddy, configure the DNS records recommended by GitHub Pages for the custom domain, then enable HTTPS after DNS verification completes.

Domain registration and website hosting are separate. Keep your GoDaddy domain; GitHub Pages can host this static landing page for free.

## Files

- `index.html` — page copy and structure
- `assets/styles.css` — responsive luxury styling and typography
- `assets/script.js` — accessible pause/play control for background motion
- `assets/hero-fallback.svg` — local background fallback

The video background and Google Fonts load from third-party servers. Browser autoplay policies or network restrictions may prevent the video from playing; the fallback background will still display.
