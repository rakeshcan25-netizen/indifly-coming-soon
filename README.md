# IndiFly — Luxury Coming Soon

A single-page, static Coming Soon experience.

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.

## Deploy free
Upload this folder to Cloudflare Pages, GitHub Pages, Netlify, or Vercel.

## Customize
- Change the background image in `style.css`.
- Change the email address in `index.html`.
- Replace the headline/caption with your final launch message.
